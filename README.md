# 薯页摘录

一个本地运行的 Chrome/Edge Manifest V3 插件，用于摘录当前小红书帖文：

- 帖文标题、作者、正文、话题、页面日期和地点
- 点赞数、收藏数、评论数
- 当前页面排序下的前 50 条一级评论
- 已经显示在页面中的楼中楼回复（可关闭）
- 帖文图片（可关闭）

导出内容保存在浏览器默认下载目录的 `xiaohongshu-export` 文件夹中，包括 `note.json`、`note.md`、`comments.csv` 和图片。

## 安装

1. 打开 Edge 的 `edge://extensions` 或 Chrome 的 `chrome://extensions`。
2. 开启“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择本项目文件夹。
4. 登录小红书并打开一个帖文详情页。
5. 点击工具栏中的“薯页摘录”，再点击“开始摘录”。

## 数据范围

- 评论只取当前页面顺序的前 50 条一级评论，不代表全部评论。
- 插件不会主动展开所有楼中楼，只附带已经显示的回复。
- 图片是网页当前提供的版本，不保证为创作者上传的未压缩原文件。
- 页面只显示月日时，`publishedAtInferred` 会根据帖文 ID 推断 UTC 时间，并明确标记为非官方推断值。
- 插件不读取 Cookie、不调用未公开接口，也不会把数据上传到外部服务。
