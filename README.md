# 薯页摘录

一个本地运行的 Chrome/Edge Manifest V3 插件。它会读取当前小红书帖文，使用用户自行配置的文字与图片模型生成固定格式的中文舆情概括，并保留原始数据下载能力。接口采用 OpenAI-compatible `/chat/completions` 格式。

## 主要功能

- 提取标题、作者、正文、页面日期、地点、点赞数、收藏数和评论数
- 提取当前页面排序下的前 50 条一级评论及已经显示的回复
- 使用可配置的图片模型逐图提取文字与关键视觉信息
- 使用可配置的文字模型综合正文、图片证据和评论观点
- 生成“一行星号标题 + 一整段正文 + 小红书完整页面链接”的固定格式
- 一键复制、重新生成，或下载 JSON、Markdown、CSV 和帖文图片

## 安装与首次设置

1. 打开 Edge 的 `edge://extensions` 或 Chrome 的 `chrome://extensions`。
2. 开启“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择本项目文件夹。
4. 打开插件，点击右上角“设置”。
5. 分别填写文字模型与图片模型的 API 地址、模型名称和 API Key。
6. 点击两个“测试”按钮确认连通，再保存设置。
7. 登录小红书，打开一个帖文详情页，点击“提取并概括”。

推荐预设（所有字段都可以修改）：

- DeepSeek：`https://api.deepseek.com`，模型 `deepseek-v4-flash`
- Qwen：`https://dashscope.aliyuncs.com/compatible-mode/v1`，模型 `qwen3-vl-plus`

也可以改用其他提供 OpenAI-compatible Chat Completions 接口的模型。保存或测试时，浏览器会针对所填写的 HTTPS API 域名单独请求访问权限。

## 数据与密钥

- API Key 默认使用 `chrome.storage.local` 仅保存在本机浏览器配置中，重启后无需重填；可以在设置页切换为关闭浏览器后自动清除的会话模式。
- 本机密钥存储被限制为仅插件可信页面和后台程序可访问，内容脚本无法直接读取；设置页提供一键清除密钥。
- 本机保存侧重个人设备上的使用便利，并非独立加密保险箱；能够控制浏览器配置文件的程序仍可能读取其中数据。
- 非敏感模型配置使用 `chrome.storage.local` 保存。
- 本次采集数据、图片识别结果和概括结果进入浏览器会话缓存，不会自动下载。
- 图片二进制不会写入缓存；需要识别时由扩展后台读取并临时转换为 Base64。
- 内容只发送给用户配置的文字与图片模型 API，不经过中转服务器。
- 插件不读取 Cookie，也不调用小红书未公开接口。

## 数据范围与容错

- 评论只取当前页面顺序的前 50 条一级评论，不代表全部评论。
- 插件不会主动展开全部楼中楼，只附带已经显示的回复。
- 图片是网页当前提供的版本，不保证为创作者上传的未压缩原文件；单图最大处理 12 MB，单帖最多处理 18 张。
- 图片模型调用失败时会继续进行文字概括，并在结果中显示警告。
- “重新生成”会复用页面采集和图片识别缓存，只重新调用文字模型。
- 点赞数、评论数和采集时的完整页面链接由插件确定性写入，不交给模型自由生成，也不会根据帖文 ID 重新拼接链接。
