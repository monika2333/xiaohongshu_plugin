# v0.14.6 平台徽标统一为红色「小红书」

- 日期：2026-10-29
- 版本：manifest / package.json 均为 0.14.6
- 提交：与代码同一提交
- 委托：用户反馈历史列表里小红书条目的徽标显示绿色「网页」，与微博条目的「微博」不对等；当前帖文右上角虽显示「小红书」但配色是绿色。要求统一为红色、文字均为「小红书」。
- 关闭的 backlog 条目：无

## 改了什么

| 文件 | 改动 |
| --- | --- |
| `panel.js` | 5 处小红书徽标/文案统一：`platformBadge`（当前帖文）、`taskBadge`（任务条）、`basketItemLabel`（素材提示前缀）、`renderBasket`（清单条目）、`historyBadge`（历史列表）。「网页」全部改「小红书」，类名 `merge-badge-page` 改 `merge-badge-xhs`。 |
| `panel.css` | `.merge-badge-page`（绿 `--green`）改名 `.merge-badge-xhs`，背景改主题红 `--red`；截图徽标保持 `--red-dark` 深红作区分。 |
| `tests/panel.test.cjs` | 新增断言：当前帖文徽标 className 为 `merge-badge merge-badge-xhs`；历史列表内含 `merge-badge-xhs">小红书`。 |
| `manifest.json` / `package.json` / `tests/service-worker.test.cjs` | 版本 0.14.6，测试版本断言同步。 |

## 实测与验证

- `npm run check`：通过（9 个测试文件全绿）。
- 需在真实浏览器确认：历史列表、任务条、清单、当前帖文四处徽标均为红色「小红书」；微博仍为橙色「微博」。

## 偏离委托的地方

无。用户只点名历史列表与当前帖文两处；任务条、清单、素材提示前缀里的同类「网页」标签一并统一，避免同一平台两种叫法。
