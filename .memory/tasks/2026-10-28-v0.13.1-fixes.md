## 偏离委托的地方

1. 打包脚本改为手动写 zip 条目，而不是 `Compress-Archive`。原因：PowerShell 5.1 的 `Compress-Archive` 会把条目名写成反斜杠，部分商店/解压工具会误判；手动写入使用正斜杠，白名单和根目录要求不变。脚本保持纯 ASCII，避免 PS 5.1 按 ANSI 读取中文导致解析错乱。
2. 任务进行中“清空链接”没有延迟执行，而是提示「任务进行中，完成后才能清空」。委托只要求补链接延后；清空需要额外的 pending 清空状态，暂不扩大改动，已记入 backlog。
3. 当合并结果存在但清单已清空时，清单区块保持可见以承载「查看合并结果」入口，不再按“清单为空整块隐藏”完全收起；这是修复项 2 入口可用的必要条件。
4. `relinkResult` 在完全没有已存工作流状态时也不创建新状态（除 `working` 与会话不一致外）。避免为一次性/历史结果凭空生成面板工作流；已有同会话的完成态仍正常更新。
