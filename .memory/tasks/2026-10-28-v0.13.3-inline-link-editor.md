# v0.13.3 原帖链接改为行内编辑

- 日期：2026-10-28
- 版本：manifest / package.json 均为 0.13.3
- 提交：`c7a28e1`
- 委托：用户实测反馈——点击“编辑链接”后不应在下方另弹一个输入框，应让当前链接本身直接变成可编辑框。
- 关闭的 backlog 条目：无

## 改了什么

| 文件 | 改动 |
| --- | --- |
| `panel.html` / `panel.css` | 结果链接行由 grid 改为单行 flex：编辑时隐藏原来的链接文本和 ✎，在原位置显示输入框、保存和取消按钮；错误/确认提示移到链接行下方。 |
| `panel.js` | `renderResultLink` 在编辑态隐藏 `result-link-display` 与 `result-link-edit`，显示 `result-link-editor`；打开编辑时聚焦并全选现有链接。 |
| `tests/panel.test.cjs` | 补断言：编辑时原链接文本和铅笔隐藏、输入框带原值；保存后恢复链接展示。 |
| `README.md` | “指定目标补链接”补充行内编辑说明。 |
| `manifest.json` / `package.json` | 版本 0.13.3。 |
| `.memory/context.md` | 当前版本升到 0.13.3；新增“结果链接行内编辑”约定。 |
