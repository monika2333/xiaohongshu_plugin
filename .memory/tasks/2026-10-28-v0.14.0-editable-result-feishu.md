## 偏离委托的地方

1. 结果编辑只保留在当前会话的结果对象中，不写回 `chrome.storage.local` 的历史记录；历史屏中的临时编辑同样不落库。避免用户无意修改既有历史。复制与手动发送均取当前框内文本。
2. 飞书图标使用 IconPark 的 Lark 品牌路径，而不是在线加载官方图片；扩展运行时不需要额外网络请求。
3. 图标可见性以“飞书配置完整可用”为准（Webhook URL，或 App ID + App Secret + 接收人）；仅填写一部分时不显示。

## 审核备注（仅当新增权限或数据流时）

无新增权限。新增的“发送到飞书”按钮复用用户已配置的飞书凭据，只把结果框中当前（包括用户编辑后）的文本发送到用户指定的飞书群或账号；未配置飞书时按钮不会显示。
