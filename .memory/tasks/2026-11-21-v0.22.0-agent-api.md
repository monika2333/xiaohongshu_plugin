## 改了什么

| 文件 | 改动 |
| --- | --- |
| `agent-api.js`（新增） | `globalThis.SHUYE_AGENT_API`：`ping()`、`captureTab({ noteId \| tabId, commentLimit, notify, force })`、`isQuiet(tabId)`；按帖子 ID 找页签 → 检查 `web_session` → 注入采集脚本 → 轮询 `XHS_PAGE_CONTEXT` 等详情就绪 → 发 `XHS_CAPTURE_AND_SUMMARIZE`；返回 `text`、`historyId`、`notification` 与精简 `meta` |
| `service-worker.js` | `importScripts` 加 `agent-api.js`；`summarizePayload` 支持 `options.skipNotify`；`summarizePagePayload` 对静默页签传 `skipNotify` |

| `tests/agent-api.test.cjs`（新增） | 正常采集、静默开关与解除、失败时解除静默、前置检查、不新增权限与外部监听 |
| `tests/service-worker.test.cjs` | 版本号；静默页签不推送飞书、不查询面板 |
| `README.md`、`AGENTS.md`、`.memory/context.md` | 入口说明、打包清单、模块地图与数据流 |

## 实测与验证

- `npm run check`：通过
- 本机实测：用模拟的小红书页面和模拟模型接口，在 Chrome 153（`--enable-unsafe-extension-debugging` + `Extensions.loadUnpacked`）里经 CDP 调用 `captureTab`，整条链路（注入、详情就绪、采集、概括、写历史）走通，返回 apiVersion 1 与渲染好的摘要；未配置 Key 时把「尚未配置模型 API Key」原样抛回调用方。
- 需要在真实浏览器里验证：用 `--remote-debugging-port` 启动专用浏览器，加载本版本，打开一条帖文详情页，经 CDP 连到扩展 service worker 执行 `SHUYE_AGENT_API.captureTab({ noteId, notify: false })`，应返回概括文本、写入历史、不推送飞书。
